¿Qué es GitHub? GitHub es una plataforma en la nube que permite a los desarrolladores almacenar, gestionar y colaborar en proyectos de código fuente utilizando el sistema de control de versiones Git.

¿Qué espero aprender al utilizar repositorios? Yo espero aprender conceptos esenciales, asi como a crear espacios de trabajo (locales y remotos) donde se almancena todo el historial y los archivos de mis proyectos.
